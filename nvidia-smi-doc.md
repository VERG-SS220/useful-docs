# Как пользоваться nvidia-smi максимально эффективно для отслеживания состояния карт
Во время работы с определенными видеокартами от NVIDIA, могут случаться некоторые сложности с определением того, в каком режиме у нас
работают видеокарты, поскольку у нас не было чёткого метода определения ширины канала и поколения PCI-E, которое используется
на них. Я провёл определённое количество времени за изучением переменных в `nvidia-smi` и мне удалось собрать некоторую полезную
информацию.
## Каким образом изначально определяются карты
Изначально карты у нас определяются при помощи драйверов NVIDIA, которые можно установить через apt, либо по прямой ссылке [здесь](https://us.download.nvidia.com/XFree86/Linux-x86_64/610.57.04/NVIDIA-Linux-x86_64-610.57.04.run). Предпочтительно использовать apt, поскольку пакет `nvidia-driver-610-open` обновляется ВМЕСТЕ с системой и файл `NVIDIA-Linux-x86_64-610.xx.xx.run` не придётся запускать каждый раз с обновлением системы. Люди чаще используют .run файл на Ubuntu, поскольку люди могут не знать о существовании пакета.

Бывает достаточно неудобно если нужно посмотреть параметры, которые тут недоступны.

* `nvidia-smi --query-gpu=` используется для просмотра определенных параметров карт(-ы) без больших полотен текста как при `nvidia-smi -q`, которая выводит инфу ВООБЩЕ обо всём. Основные полезные параметры:
 * `nvidia-smi --query-gpu=pcie.link.gen.current,pcie.link.gen.max,pcie.link.width.current,pcie.link.width.max --format=csv` выводит информацию о поколении(текущем и максимальном) PCIE, а также ширину линии (также текущую *и* максимальную), поскольку `lspci` у нас часто выдавал какой-то бред типо вот такого:
```
		LnkCap:	Port #0, Speed 5GT/s, Width x32, ASPM L0s, Exit Latency L0s <64ns
		LnkSta:	Speed 5GT/s, Width x32
		LnkCap:	Port #0, Speed 5GT/s, Width x32, ASPM L0s, Exit Latency L0s <64ns
		LnkSta:	Speed 5GT/s, Width x32
```

Очевидно, что карты **НЕ МОГУТ** выдать ширину линии 32 со скоростью 5 Гигатрансферов в секунду. Особенно на виртуалных машинах под ESXi, Virtualbox и т.д. Поэтому в информацию, выводимую с `lspci` верить категорически нельзя, ибо сами карты не могут работать в таком режиме и опираться нужно в любом случае использовать утилиту от NVIDIA.

## Более точные данные, нежели чем с NVIDIA-SMI
Более точные данные может предоставить программа в Python 3 под названием `nvitop`. Собрать её в убунту можно несколькими способами:
1. Если вдруг вам нужно её использовать в качестве дополнительной утилиты внутри проекта на Python:
```bash
# Создаём папку для использования утилиты. (Можно пропустить, но будет удобнее, если будет отдельная папка)
mkdir <любое название папки> ; cd <название только что созданной папки>
# Установка python3-pip и python3-venv для установки пакетов 
sudo apt install -y python3-venv python3-pip ; python3 -m venv . ; cd bin ; source activate
# Установка nvitop через pip в виртуальной среде.
pip install nvitop
# После установки запускаем сам мониторинг
nvitop
```
ИЛИ
2. Установка нативно через apt
`sudo apt install nvitop` если вам проще будет (а вам БУДЕТ проще) использовать утилиту без использования 

Откроется панель мониторинга, которая выводит куда больше информации, чем стандартный `nvidia-smi`. К примеру, дополнительно выводятся графики использования CPU и оперативной памяти (как в htop), а также график использования видеопамяти, в процентах.

## Пример некоторых запросов, которые помогут помогут определить характеристики и состояние карты
* `nvidia-smi --query-gpu=index,name,pci.bus_id,temperature.gpu,temperature.memory,memory.used,pcie.link.gen.current,pcie.link.width.current,power.draw --format=csv,nounits` помимо поколения PCIе, позволяет увидеть имя карты, её индекс (положение в nvidia-smi), ID шины PCI-E (к примеру, 00:13:00.0), температуру памяти и ядра, потребление энергии, а также статистику по шине PCI (поколение и ширина).
* `nvidia-smi -q | grep -A 4 "Clocks Throttle Reasons"` показывает причины троттлинга карт(-ы) (уменьшения производительности) в связи с повышенной температурой, программным ограничением по питанию и пр.
* `nvidia-smi --query-gpu=index,clocks.current.graphics,clocks.current.memory,clocks.max.graphics,clocks.max.memory` показывает текущую и максимально возможную частоту ядра и видеопамяти.
* `nvidia-smi --query-gpu=index,pstate` показывает в каком состоянии питания находится сейчас видеокарта. Может быть в значениях от P0 (Максимальная производительность) до Р12 (минимальная производительность)
* `nvidia-smi --query-gpu=fan.speed` указывает на скорость вращения вентилятора (в CMP170HX вентилятор отсутствует, за сим данный запрос будет иметь поле N/A).
> Дальнейший список полезных утилит будет пополняться, поэтому данный список НЕ является полным/исчерпывающий.
